# Lightroom Wheel 0.2 — ตัวช่วยฟรีสำหรับ Mac Apple Silicon

ชี้เส้นสไลเดอร์ใน Lightroom Classic แล้วหมุนล้อเพื่อปรับค่า ใช้แอป Swift กับปลั๊กอิน Lua ฟรี ไม่ต้องสมัครบริการเพิ่ม แต่ยังต้องมี Lightroom ที่ใช้งานได้ตามปกติ

**รุ่นทดลอง:** ยืนยันด้วยเมาส์จริงแล้วว่าชี้ Exposure และปรับ Exposure ได้ตรงตัวหลังแก้พิกัด ยังไม่ได้ทดสอบครบทุกสไลเดอร์ ทุกจอ และทุกเวอร์ชัน

## ติดตั้งและใช้

1. ดาวน์โหลด ZIP จากหน้า Releases แล้วแตกโฟลเดอร์ LightroomWheel ทั้งชุดไว้ในตำแหน่งที่เขียนไฟล์ได้
2. เก็บ Lightroom Wheel.app และ Lightroom Wheel.lrplugin ไว้ข้างกัน
3. ใน Classic เปิด File → Plug-in Manager → Add แล้วเลือก Lightroom Wheel.lrplugin และเปิดใช้งาน หากไม่เริ่ม ให้เลือก File → Plug-in Extras → Start Lightroom Wheel Bridge
4. เปิดแอปตัวช่วย อนุญาต Accessibility และ Screen Recording ให้ Lightroom Wheel แล้วเปิดแอปใหม่
5. ตัวช่วยเริ่มเองเมื่อสิทธิ์และปลั๊กอินพร้อม คลิกกลับ Classic เปิด Develop → Basic ภาษาอังกฤษ เลือกภาพเดียว แล้วชี้เส้นสไลเดอร์ก่อนหมุนล้อ

หากไม่ต้องการเสียบ SSD ให้เก็บทั้งโฟลเดอร์ไว้ที่ `~/Applications/LightroomWheel` บน Mac แล้วเลือกปลั๊กอินจากตำแหน่งนี้ใน Classic และปิดปลั๊กอินตัวเก่า หากต้องการเปิดพร้อมเข้าเครื่อง ให้เพิ่มแอปใน System Settings → General → Login Items → Open at Login โดยตั้งแยกแต่ละเครื่อง

การเริ่มอัตโนมัติอยู่ในซอร์สบน main ส่วน ZIP v0.2.0 เดิมยังต้องกดเริ่ม ให้คอมไพล์จากซอร์สเพื่อใช้พฤติกรรมใหม่ ตัวช่วยรอสิทธิ์และปลั๊กอินโดยลองใหม่ทุก 5 วินาที ไม่สลับหน้าต่าง Classic การกดหยุดมีผลเฉพาะรอบนี้ เปิดแอปใหม่จะเริ่มเองอีกครั้ง หากกดออก จะหยุดจนเปิดเองหรือเข้าสู่ระบบครั้งถัดไป

รองรับ Apple Silicon ตั้งเป้าระบบ macOS 14.2 ขึ้นไป แต่ทดสอบจริงเฉพาะเครื่อง M4 กับ Classic 15.6 ยังไม่ได้ยืนยันระบบรุ่นเก่าทั้งหมด แอปเซ็นภายในเครื่องและยังไม่ notarize; macOS อาจต้องให้อนุญาตเปิดแอปที่ดาวน์โหลดมา หรือเลือกคอมไพล์เองจากซอร์สได้

## ปุ่มควบคุม

- หมุนขึ้นเพิ่มค่า หมุนลงลดค่า
- Shift + หมุน: Exposure ทีละ 0.01 แทน 0.05
- Control + หมุน: เร็วขึ้น 5 เท่า
- Option + หมุน: เลื่อนแผงตามปกติ
- หยุดหรือออกได้จากไอคอนเมาส์บนแถบเมนู macOS

เมาส์บางรุ่นส่งหลายหน่วยต่อหนึ่งกิ๊ก หลังเลื่อนแผงหรือเปลี่ยนภาพ รอประมาณหนึ่งวินาทีให้ตำแหน่งอัปเดต Classic ต้องอยู่ด้านหน้าใน Develop และเลือกภาพเดียว

## ขอบเขตและข้อจำกัด

กำหนดให้รองรับ Temp, Tint, Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Texture, Clarity, Dehaze, Vibrance และ Saturation ใน Basic เมื่ออ่านชื่อได้ชัดเจน เน้น JPEG; ยังไม่รองรับ Temp แบบ Kelvin ของ RAW, Mask, Curve หรือ Color Mixer

ใช้ OCR หาตำแหน่งชื่อสไลเดอร์ และอ่าน/ปรับตัวเลขผ่าน Lightroom SDK จึงยังมีความหน่วงและอาจอ่านชื่อไม่พบเมื่อแผงขยับหรือมีสิ่งบัง ยังไม่ผ่านการทดสอบหลายจอ แนะนำลองบน Virtual Copy ก่อนใช้งานสำคัญ

ภาพหน้าจอใช้ในหน่วยความจำ ไม่บันทึกและไม่ส่งออนไลน์ แอปกับปลั๊กอินคุยผ่านไฟล์ใน Lightroom Wheel.lrplugin/bridge ซึ่งมีรหัสภาพภายในแค็ตตาล็อกและค่าปรับ ไฟล์เหล่านี้ไม่รวมใน Git หรือ ZIP เผยแพร่ ค่าที่เปลี่ยนบันทึกในแค็ตตาล็อก Lightroom ไม่เขียนทับ JPEG ต้นฉบับ

ถ้าอยู่บน SSD ต้องต่อ SSD ขณะใช้ และต้องเก็บแอปกับปลั๊กอินข้างกัน การคอมไพล์แอปใหม่อาจต้องรีเฟรชสิทธิ์ของ Lightroom Wheel

## คอมไพล์และทดสอบ

ติดตั้ง Xcode Command Line Tools จาก Apple แล้วรัน `./test.sh`, `./build.sh` และ `python3 package.py` ตามลำดับ ผลลัพธ์อยู่ใน dist/LightroomWheel ดูผลทดสอบและขอบเขตที่ยืนยันแล้วใน TEST-RESULTS.txt

เผยแพร่ภายใต้ MIT ใช้และพัฒนาต่อได้ โครงการอิสระ ไม่เกี่ยวข้องกับ Adobe
